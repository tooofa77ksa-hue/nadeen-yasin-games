# نماذج الشخصيات ثلاثية الأبعاد (GLB)

الاتجاه: +Z للأمام، Y للأعلى، الوحدة متر، نقطة الأصل عند منتصف القدمين، والبالغ طوله ١٫٧.
الوضع الافتراضي: الذراعان نازلتان قليلاً. المحاور (pivots) عند المفاصل، فأي برنامج يحرّك العقد بالتدوير مباشرة. الوجوه مدمجة داخل الملف. لا توجد حركات مضمّنة (الحركات في `lib/avatar.js` كمرجع).

| الملف | الوصف |
|---|---|
| mother.glb | الأم: ثوب طويل داكن وحجاب |
| son.glb | الابن الصغير (٦٠٪): قميص أصفر وجينز |
| boy_thobe.glb | ولد بثوب أبيض وطاقية بيضاء (معه كأس ماء عقدة `glass` على اليد اليمنى) |
| kid1.glb … kid7.glb | سبعة أطفال بألوان زاهية (ولد/بنت، البنات بحجاب وثوب طويل) |
| horse_cart.glb | الحصان والعربة |

## أسماء العقد (الشخصيات)
`hips` (الحوض) ← `torso` ← `head` (محور الرقبة) + `arm_L` ← `forearm_L` ← `hand_L`، وكذلك `arm_R`. الساقان تحت `hips`: `leg_L` ← `shin_L`، و`leg_R` ← `shin_R`. (L = يسار الشخصية = جهة +X).

## الحصان والعربة
`body` تحته `head` و`tail` و`leg_FL leg_FR leg_BL leg_BR` (ولكلٍّ `shin_..`)، والتدوير حول Z. العربة `cart` تحتها `wheel_L` و`wheel_R` (تدور حول Z). الحصان يتجه نحو +X والعربة خلفه.

المعاينات في `previews/`. إعادة التصدير: `npm i` ثم `node ../export.js` من هذا المجلد (أو `node export.js` من 3d).
